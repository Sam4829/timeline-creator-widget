# Timeline Estimator — Figma Plugin

A Figma plugin for creating beautiful, editable timeline estimation tables directly in your design file.
Built for the Polaris D&E team (and anyone who needs structured timelines fast).

---

## Features

- ✦ **Editable columns** — rename, reorder (drag), add/remove, set type (Date / Text / Status)
- ✦ **Real date picker** — native calendar input for every date cell
- ✦ **Status badges** — WIP, Done, Yet to start, Blocked, In review (auto-styled)
- ✦ **3 built-in templates** — Polaris D&E, Design Sprint, Dev Timeline
- ✦ **Dark / Light theme** — matches your Figma file's vibe
- ✦ **Auto-positions** on canvas, never overlaps existing frames

---

## Install locally (Development)

1. Open **Figma Desktop**
2. Go to **Plugins → Development → Import plugin from manifest...**
3. Select the `manifest.json` file from this folder
4. The plugin appears under **Plugins → Development → Timeline Estimator**

> Requires Figma Desktop — browser Figma doesn't support local plugin loading.

---

## Usage

1. Open the plugin from the menu
2. **Setup tab** → enter project name, pick theme, or load a template
3. **Columns tab** → add/rename/reorder/delete columns; set type per column
4. **Rows tab** → add tasks, fill in dates (real calendar picker!), set status per row
5. **Preview tab** → confirm the layout looks right
6. Click **▶ Generate in Figma** → table appears on the canvas

## Publish to Figma Community (share with anyone)

### Step 1: Get a Figma account with publishing rights
You need a Figma account (free or paid). Community publishing is free.

### Step 2: Create the plugin entry
1. Open Figma Desktop
2. Go to the **Community** tab → **Publish plugins**
3. Click **"New plugin"**
4. Choose **"Figma Design"** as the editor type
5. Upload or point to your plugin folder

### Step 3: Bundle the plugin
The plugin is built using Preact and TypeScript. Run `npm run build` to compile the source code into the `build/` directory which Figma consumes directly.
During development, use `npm run watch` for incremental rebuilds.
The `manifest.json` is auto-generated by `@create-figma-plugin/build` from the `figma-plugin` key in `package.json`.

### Step 4: Add metadata for the store listing
Edit the `figma-plugin` key in `package.json` to set:
- `name` — Plugin display name
- `id` — Figma assigns this when you register
- `editorType` — `["figma"]`

The build step will generate the correct `manifest.json` automatically.

### Step 5: Submit for review
- Add a cover image (1920×960px recommended)
- Write a description (markdown supported)
- Submit — Figma reviews within a few days
- Once approved, anyone can install it from the Community tab

### Instant sharing (no review needed)
Share the plugin folder as a ZIP. Anyone can install it locally via
**Plugins → Development → Import from manifest**.

## Customisation tips

**Add more status options** — in `src/ui.tsx`, find the status dropdown options and add values.
**Change default column widths** — in `src/main.ts`, adjust the `FIRST_W`, `DATE_W`, `RANGE_W`, and `OTHER_W` constants.
**Add a new template** — in `src/ui.tsx`, add an entry to the `handleTemplateChange` template generation logic.
**Change fonts** — in `src/main.ts`, replace `'Inter'` with any Google Font available in Figma.
